# Seb's Fun Stuff 🎬

A little website for showing my videos to Mum and Dad.

## How to add a video
1. Put the video file (like `dance.mp4`) in the `videos` folder.
2. Open `videos.js` and add a line like:
   `{ file: "dance.mp4", title: "The girls dancing", date: "8 Oct 2026", note: "So funny!" },`
3. Open `index.html` to see it.

⚠️ Ask Mum or Dad before putting this website on the internet. Videos of
my sisters should only be seen by our family.
