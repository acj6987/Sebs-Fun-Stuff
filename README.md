# Monster Quest 3D

A 3D monster-catching adventure game. Open `index.html` in a web browser to play.

- Play as **Seb Jumpstone**, **Z Jumpstream**, **Galley** or **Josh Clark** (the others are your friends in the world, and you can chat with them).
- Catch 25 original monsters across 9 lands, find treasure chests, win 4 Stadium badges, then beat the Champion in the Grand Stadium.
- Climb the floating islands in Cloud Heights to find the legendary Jumpstar.

Controls: WASD / arrows to move, Space to jump, E to talk / enter / open, drag to look around. On a phone or tablet, use the on-screen joystick and buttons.
